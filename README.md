- 🎓 **Education:** B.Tech in CSE with Artificial Intelligence & Machine Learning at SRMIST KTR
- 🚀 **Currently Building:** AI-integrated campus platforms, digital trust tooling, and serverless edge architectures
- 💡 **Core Interests:** Distributed systems, Explainable AI, PWA development, and developer productivity tools
